# Weather Analyzer 🌤️

A Python data analysis project that analyzes weather data from Szeged (2006-2016).

## Project Overview

This project loads weather data from a CSV file and performs comprehensive statistical analysis including temperature trends, humidity patterns, wind speed analysis, and monthly comparisons.

## Features

- **Temperature Analysis**
  - Calculate average temperature
  - Find hottest and coldest days
  - Monthly temperature trends

- **Wind Speed Analysis**
  - Average wind speed
  - Highest and lowest wind speeds
  - Identify windiest days

- **Humidity Tracking**
  - Average humidity levels

- **Precipitation Analysis**
  - Count rainy days

- **Monthly Grouping**
  - Average temperature by month
  - Warmest and coldest months

## Learning Outcomes

This project demonstrates:
- CSV file handling
- Object-oriented programming with dataclasses
- Data analysis and statistics
- Lambda functions and comprehensions
- File I/O operations
